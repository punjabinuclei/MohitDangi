Shubham Dangi - Architectural Portfolio
A modern and visually stunning architectural portfolio website built using React, Vite, TypeScript, ShadCN, and TailwindCSS. This platform highlights architectural projects with a clean, interactive, and highly optimized user experience.

Key Features:
Lightning-Fast Performance: Powered by Vite for near-instant page loads and smooth interactions.
Type-Safe Development: Built with TypeScript for maintainable and scalable code.
Modern UI Components: Utilizing ShadCN for sleek and accessible design elements.
Responsive & Aesthetic: Styled with TailwindCSS for a seamless experience across all devices.
Project Showcase: A visually rich gallery to display architectural works with descriptions and high-quality images.
Interactive Animations: Smooth transitions and micro-interactions for an engaging experience.
Contact & Inquiry Form: Easy-to-use form for project inquiries and collaborations.
This website serves as a digital portfolio for Shubham Dangi, blending architectural design with modern web technologies to create a professional online presence. 🚀
